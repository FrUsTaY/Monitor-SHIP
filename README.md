# 🚢 Мониторинг пароходов со спутниковым интернетом

## 📌 Описание проекта
Приложение предназначено для **непрерывного мониторинга доступности спутникового интернета** на пароходах.  
Оно проверяет IP-адреса модемов (с помощью ICMP и TCP-проверок), отображает статус каждого судна в реальном времени и ведёт **журнал потерь пакетов** для анализа стабильности связи.

Программа разработана для **администраторов спутниковых сетей** и позволяет:
- Отслеживать доступность десятков судов одновременно в асинхронном режиме.
- Настраивать чувствительность к сбоям (интервалы опроса, пороги перехода статусов).
- Блокировать суда на время обслуживания.
- Вести заметки для каждого судна (например, "Судно в порту", "Технические работы").
- Сохранять часовую статистику потерь и формировать отчёты по каждому судну за любой период.

## ✨ Возможности (Версия 2.2)
- **Многопоточный асинхронный опрос**: Быстрая проверка всех судов одновременно (с использованием ICMP-пинга и резервной проверки TCP-порта).
- **Продвинутая система логирования с защитой данных**: Многоуровневая защита логов сохраняет данные на диск каждые 10 секунд, чтобы исключить потерю информации даже при внезапном отключении ПК (влияние на производительность минимально).
- **Система заметок**: Возможность добавления поясняющих текстовых заметок к судам. Заметки отображаются в реальном времени в мониторинге и сохраняются в логах (как в ежечасных отчётах, так и при смене статуса).
- **Интерактивный интерфейс командной строки**: Удобное меню, очистка терминала, цветная индикация статусов и структурированный табличный вывод.
- **Сглаживание ложных срабатываний**: Настраиваемые пороги последовательных успехов/неудач для предотвращения ложных переходов в оффлайн из-за кратковременных сбоев.
- **Блокировка судов**: Исключение выбранных судов из цикла мониторинга на период ремонта или стоянки.
- **Генерация отчётов**: Выгрузка подробной хронологической статистики потерь по конкретному судну за любой выбранный период.

## 🚀 Установка и запуск

### Требования
- **Python 3.8** или выше (скачать с [python.org](https://python.org)).
- Операционная система: Windows, Linux или macOS.
- Права на запуск команд `ping` (в Windows может потребоваться запуск от имени администратора, если антивирус блокирует ICMP).
- Дополнительных библиотек не требуется — используются исключительно встроенные модули Python.

### Установка
1. Клонируйте репозиторий или скачайте все файлы проекта в одну папку.
2. Убедитесь, что Python установлен и добавлен в системную переменную `PATH`.

### Запуск
```bash
python main.py
```

*Совет для пользователей Windows:* Вы можете создать или использовать существующий файл `start_monitor.bat` в папке с программой для удобного запуска двойным кликом.

## 🧭 Использование

При запуске программы открывается главное меню:

1. **Показать список судов** – Выводит все суда с их статусами, соединениями и заметками.
2. **Добавить новое судно** – Интерактивное создание судна и добавление одного или нескольких спутников (IP).
3. **Удалить судно** – Удаление судна по порядковому номеру или названию.
4. **Редактировать судно** – Изменение IP-адресов, удаление/добавление спутников, переключение блокировки и редактирование заметок.
5. **Заблокированные суда** – Просмотр и разблокировка судов, временно снятых с мониторинга.
6. **Обновить статусы (ручной опрос)** – Единоразовая принудительная проверка всех активных судов.
7. **Запустить непрерывный мониторинг** – Переход в режим мониторинга в реальном времени с циклической перерисовкой таблицы (для остановки нажмите `Ctrl+C`).
8. **Настройки мониторинга** – Изменение интервала опроса, порогов сглаживания и целевого TCP-порта.
9. **Выгрузить лог по судну** – Формирование отчёта для выбранного судна за указанный период.
0. **Выход**

### 📝 Работа с заметками
Заметки помогают администратору и коллегам понимать причину текущего статуса судна (например, почему оно оффлайн).
- **Добавление / Очистка**: В главном меню выберите "4. Редактировать судно" -> Введите номер/имя судна -> Выберите "5. Редактировать заметки".
- **Отображение**: Заметки выводятся в общем списке судов, в таблице мониторинга (пункт 7) и добавляются в лог-файлы при смене статуса или в ежечасный лог.

## 🔍 Как работает мониторинг

- **Комбинированная проверка**: Каждое судно проверяется сначала классическим ICMP-запросом. Если пинг не проходит, осуществляется попытка установки соединения на заданный TCP-порт (по умолчанию 22). Если хотя бы одна из проверок на любой из IP-адресов судна успешна — судно считается находящимся "в сети".
- **Логика сглаживания**:
  - `Offline Threshold` – количество неудачных циклов проверки подряд, необходимых для перевода судна в статус «не в сети» (по умолчанию 3).
  - `Online Threshold` – количество успешных проверок подряд для возврата судна в статус «в сети» (по умолчанию 1).
- Интервал между проверками можно менять в меню "8. Настройки мониторинга" (по умолчанию 10 секунд).

## 📊 Система логирования

Логи надёжно защищены от случайной потери данных. Специальный фоновый процесс синхронизирует (flush/fsync) открытые лог-файлы на диск каждые 10 секунд. Все логи сохраняются в автоматически создаваемую директорию `logs/`.

- **Ежечасные отчёты (`logs_ГГГГ-ММ-ДД.log`)**: В начале каждого нового часа (по системному времени) записывается статистика потерь пакетов (в %) за прошедший час. К записям автоматически прикрепляются методы подключения и заметки.
- **Лог смены статуса**: Момент перехода судна из сети в оффлайн (и наоборот) фиксируется мгновенно с точным timestamp.
- **Остановка сессии (Ctrl+C)**: При ручной остановке мониторинга до завершения текущего часа программа предложит сохранить статистику за неполный час.
- **Генерация отчётов (`report_ИМЯ_ГГГГММДД_ГГГГММДД.txt`)**: В пункте 9 меню вы можете выбрать судно и временной диапазон (указав количество дней или точные даты), чтобы программа сформировала выгрузку всех записей по этому судну.

## ⚙️ Конфигурация и данные

Данные приложения сохраняются локально в JSON-файлах, которые программа создаёт автоматически (ручное редактирование не обязательно):
- `ships.json` — база данных судов (содержит названия, IP-адреса, текущие статусы, флаги блокировки и заметки).
- `config.json` — глобальные параметры мониторинга:
  - `monitor_interval` — пауза между циклами проверок (сек).
  - `offline_threshold` / `online_threshold` — пороги сглаживания.
  - `tcp_port` — порт для резервной TCP-проверки.
